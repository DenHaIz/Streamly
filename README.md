# Streamly

<p align="center"><img src="resources/icon.png" width="96" alt="Streamly"></p>

**RU.** Streamly — простой аналог Parsec для компании друзей. Один нажимает «Я хост», остальные нажимают «Подключиться» и через Radmin VPN попадают на его рабочий стол. Одновременно можно подключить до 4 человек. Хост на лету выдаёт и отключает каждому клавиатуру, мышь и геймпад. Внутри работают Apollo (форк Sunshine) и Moonlight. Установка, сопряжение и подключение происходят автоматически. Интерфейс на русском и английском, есть светлая и тёмная темы.

**EN.** Streamly is a simple Parsec-like app for a group of friends. One person presses "I'm the host", the others press "Connect" and join the host's desktop over Radmin VPN. Up to 4 players can connect at once. The host can grant or revoke keyboard, mouse and gamepad access for each player on the fly. Under the hood it uses Apollo (a Sunshine fork) and Moonlight. Setup, pairing and connection are automatic. The interface comes in Russian and English, with light and dark themes.

---

Внутри работают готовые открытые проекты:
- [Apollo](https://github.com/ClassicOldSong/Apollo) (форк Sunshine) на стороне хоста. Он захватывает экран и звук и эмулирует клавиатуру, мышь и геймпады через ViGEmBus. Права у каждого клиента свои.
- [Moonlight](https://github.com/moonlight-stream/moonlight-qt) на стороне друга, показывает стрим.
- [Radmin VPN](https://www.radmin-vpn.com/) даёт общую виртуальную сеть 26.x.x.x.

Streamly сам ставит и настраивает Apollo, сопрягает Moonlight с хостом (PIN вводить не нужно) и управляет правами.

> **Друзьям:** короткая инструкция по установке и подключению — [INSTALL.md](INSTALL.md).

## Что ставится на компьютеры

- **Хост.** Streamly сам и за одно окно UAC ставит Apollo: службу, драйвер виртуального дисплея SudoVDA, драйвер геймпадов ViGEmBus и правила файрвола. Если драйвер геймпадов не встал, на панели хоста есть кнопка «Установить драйвер». Служба Apollo работает только пока включён режим хоста.
- **Друг.** Ничего: Moonlight уже в комплекте вместе со своими библиотеками.
- **Все.** Radmin VPN каждый ставит сам. Streamly покажет ссылку и короткую инструкцию.

## Как пользоваться

1. Все ставят Radmin VPN. Хост создаёт сеть («Сеть» → «Создать сеть»), друзья в неё входят. Streamly покажет эту инструкцию, если Radmin не найден.
2. Все ставят Streamly и при первом запуске выбирают язык, тему и ник.
3. **Хост** нажимает «Я хост».
   - В первый раз Windows один раз попросит права администратора. Streamly тихо установит Apollo и добавит правило файрвола.
   - Дальше на экране будут адрес хоста, свободные места и входящие запросы.
4. **Друг** нажимает «Подключиться».
   - Хосты в сети Radmin находятся автоматически. Если не нашлись, адрес можно ввести вручную.
   - Хост видит запрос и выбирает «Разрешить» (один раз) или «Всегда разрешать» (друг становится доверенным и дальше заходит без подтверждения).
   - Сопряжение и запуск Moonlight происходят сами.
5. В карточке каждого игрока хост переключает **Клавиатуру**, **Мышь** и **Геймпад** (изменения применяются сразу) или отключает игрока.

В окне стрима `Ctrl+Alt+Shift+X` переключает полный экран, а `Ctrl+Alt+Shift+Q` завершает трансляцию.

## Как это устроено

```
Друг (Streamly)                                       Хост (Streamly)
 ClientController ──WebSocket :47900 (сигнализация)──► HostController ──https://127.0.0.1:47990──► Apollo
       │                                                      │                                       ▲
       │ UDP :47901 поиск (broadcast + ARP-соседи Radmin)◄─────┘                                       │
       ▼                                                                                               │
 Moonlight.exe (portable) ──────────────── поток GameStream (47984–48010) ───────────────────────────┘
```

- **Доступ:**
  - Пока друг не допущен через Streamly, у его клиента в Apollo права `perm = 0`. Поэтому подключиться напрямую из Moonlight в обход приложения нельзя.
  - Раз в 2 секунды хост сверяет список клиентов Apollo и отключает чужие подключения и всех сверх лимита.
- **Сопряжение:**
  - Хост придумывает PIN и отправляет его клиенту.
  - Клиент запускает `Moonlight pair <ip> --pin NNNN`.
  - Хост передаёт тот же PIN в `POST /api/pin` Apollo.
  - Сопряжения выполняются строго по одному, потому что Apollo применяет PIN к первому ожидающему.
- **Права** — битовая маска Apollo (`src/shared/perms.ts`). Apollo меняет их в активной сессии без переподключения.
- **Остановка хоста** снимает права у всех и рвёт сессии. Выход из приложения делает то же самое.

### Структура

| Путь | Что там |
|---|---|
| `src/shared/` | Протокол Streamly, контракт IPC, типы, права |
| `src/main/services/apollo/` | Клиент API Apollo, установка с UAC |
| `src/main/services/host/` | Логика хоста: запросы, сопряжение, права, лимит |
| `src/main/services/client/` | Логика клиента: поиск, подключение, запуск Moonlight |
| `src/main/services/moonlight/` | Командная строка Moonlight |
| `src/main/services/net/` | Обнаружение Radmin и поиск хостов |
| `src/renderer/` | Интерфейс: React, Framer Motion, i18next (ru/en), светлая и тёмная темы |
| `src/renderer/src/dev/mockBridge.ts` | Фейковый API, чтобы открывать интерфейс в браузере |

## Разработка

Нужен Node.js 22.12+.

```bash
npm install
npm run dev          # Electron с горячей перезагрузкой
npm run dev:web      # только интерфейс в браузере (http://localhost:5199) с фейковым API
npm test             # модульные тесты и сквозной сценарий хост ↔ клиент
npm run typecheck
```

Параметры `dev:web`:
- `?lang=en` — английский интерфейс;
- `?theme=light` — светлая тема;
- `?onboarded=0` — показать первый запуск;
- `?radmin=0` — Radmin не подключён;
- `?install=1` — Apollo не установлен;
- `?fail=1` — ошибка подключения;
- `?noanim=1` — без анимаций.

Переменные окружения для отладки:
- `STREAMLY_PROFILE=имя` — отдельная папка настроек, чтобы запустить второй экземпляр на одном ПК.
- `STREAMLY_DEV_IP=192.168.1.5` — адрес хоста, когда Radmin нет и проверка идёт по обычной LAN.
- `STREAMLY_ALLOW=192.168.1.7,192.168.1.8` — дополнительные разрешённые адреса клиентов.

### Сборка установщика

```bash
npm run fetch-vendor -- --pin   # скачать Apollo 0.4.6 и Moonlight 6.2.0 и записать их SHA-256 в vendor.lock.json
npm run dist                    # dist/Streamly Setup x.y.z.exe
```

При следующих запусках `npm run fetch-vendor` проверяет скачанные файлы по `vendor.lock.json`. `npm run pack` собирает распакованную версию без установщика.

## Что стоит проверить на живых ПК

Эти вещи нельзя проверить без двух компьютеров с Radmin:
- **Поиск хостов.** Доходят ли широковещательные UDP-пакеты в сети Radmin. Если нет, остаются поиск по ARP-соседям, недавние хосты и ручной ввод IP.
- **Драйвер геймпадов.** Ставит ли тихая установка Apollo (`/S`) компонент «Virtual Gamepad» (ViGEmBus). Если драйвера нет, Streamly показывает предупреждение со ссылкой.
- **Размер пакета.** Moonlight считает Radmin VPN-ом и ограничивает пакет 1024 байтами. Если картинка тормозит или рассыпается, попробуйте другой «Размер пакета» в настройках.
- **Окно сопряжения.** Окно `Moonlight pair` на мгновение появляется во время сопряжения. Streamly закрывает его сам.

## Если что-то не работает

На экране каждой ошибки есть три вещи:
- что случилось;
- что делать;
- раскрывающиеся «Подробности»: код сетевой ошибки, хвост вывода Moonlight.

Кнопка «Скопировать отчёт» кладёт в буфер обмена версии программ, состояние сети и последние строки лога. «Открыть логи» открывает `%APPDATA%\Streamly`. Там лежат:
- `streamly.log` — лог Streamly;
- `moonlight\moonlight-last.log` — вывод последнего запуска Moonlight.

Лог Apollo на хосте: `C:\Program Files\Apollo\config\sunshine.log`.
